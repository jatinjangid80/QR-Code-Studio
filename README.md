## ⚡ Features

- **7 QR Types**: URL, WiFi, vCard, UPI Payment, Plain Text, Email, and Phone/SMS.
- **Integrated Scanner**: Decode QR codes from image files or live webcam/camera.
- **Customization**: Custom colors, center badges, resolution slider, and bottom labels.
- **Dark & Light Mode**: Translucent frosted glass navbar with persistent theme memory.
- **High-Res Export**: Download branded PNGs or copy images directly to clipboard.
- **100% Private**: Zero backend — everything runs locally in your browser.

---

## 🚀 Quickstart

Open `index.html` directly in any browser, or run a local server:

```bash
# Clone the repository
git clone https://github.com/jatinjangid80/QR-Code-Studio.git
cd QR-Code-Studio

# Run locally
python3 -m http.server 8080
```

Visit: `http://localhost:8080`

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3, JavaScript (ES6+), TailwindCSS CDN
- **Libraries**: `qrcodejs`, `jsQR`
